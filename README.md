# ПР1. Ответы на контрольные вопросы
1. В С# идет обработка кода построчно и где находится ошибка, он останавливается и указывает где находится ошибка в какой строке, соответственно до компиляции, а в Python только после выполнения полной программы.
2. Она состоит из 2-х шагов, сборка и запуск кода.
3. Папка \bin хранит в себе готовую сборку как .dll и .exe. А папка \obj, постепенный файлы. Не нужно сохранять их на гитхаб, потому что они будут создаваться заново, при компиляции программы.
4. Git Commit - это сохранение каких либо файлов в один момент, а Git Push - это загрузка локальных коммитов в репозитории.
5. Конкатенация - объединение переменных вручную, а интерполяция, позволяет в любой момент времени вставлять в строку напрямую, как по мне удобней второй вариант.
6. При деление int на int дробного результата - не будет, эта частичка дроби просто теряется, а чтоб получить дробный остаток надо добавить double , тогда результат будет с дробью.
7. const отличается от обычный переменной , что он не может изменяться после того как мы его назначили, а в обычной переменной мы можем менять в любой момент. Константу нужно использовать там, где данные не должны изменяться, пример месяца.
8. Top-level statements - упрощенная версия писания программы на C#, а классический вариант требует больше времени на написания кода и он менее удобен от Top-level.
